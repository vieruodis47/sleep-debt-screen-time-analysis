# Sleep Debt & Screen Time: Late Night Phone Habits

## Project Overview
This project explores the relationships between sleep quality, screen time, and lifestyle factors using a dataset of 8,500 observations.

## Research Objectives
- Examine how late-night phone usage relates to next-day fatigue.
- Explore relationships between lifestyle factors and sleep quality.
- Predict next-day fatigue scores using regression models.
- Classify sleep debt categories using machine learning.

## Methods
- Exploratory Data Analysis (EDA)
- Data visualization with Matplotlib and Seaborn
- Linear Regression
- Multinomial Logistic Regression
- Ridge and Lasso Regularization
- Training, Validation, and Test Splitting
- Model Evaluation using Mean Squared Error (MSE)

## Tools & Technologies
Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn, Google Colab
